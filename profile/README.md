# Maya - 3D Animation, Modeling, and Rigging Platform

> **One calm creation workspace: model meshes, rig controls, and animate shots in a single editor.**

## Maya Highlights

- **Animation Suite:** Maya 3D animation covers keyframes, curves, and motion trails in one timeline.
- **Modeling Depth:** Maya modeling tools shape polygons, NURBS, and subdivision surfaces.
- **Rigging Controls:** The Maya rigging workflow builds skeletons and constraints for animators.
- **Look Development:** Maya Arnold rendering previews materials and lighting quickly.
- **USD Support:** Maya USD pipeline layers assets for large scenes.

## What Is Maya

Maya is a 3D platform for modeling, rigging, animation, and rendering. Searches such as Maya 3D animation, Maya modeling tools, Maya rigging workflow, and Maya Arnold rendering usually mean the same goal: ship a polished shot without juggling many tools.

Maya keeps the process simple. Create a scene, model the shapes, rig the character, and animate the result in one timeline. The Maya 3D animation approach favors readable panels, predictable menus, and a steady preview loop for studios, students, agencies, and product teams.

In longer sessions, Maya connects modeling and animation. Artists move from blockout to rig, then to a finished shot without switching tools. That matters when a project grows past a test and needs real deformation, materials, and performance.

Maya also fits common expectations. People checking Maya modeling tools or Maya rigging workflow usually want stable previews, clear units, and a calm path from first launch to a shippable result on everyday hardware.

## Starting with Maya

Prerequisites: A supported machine, the editor, and a first shot idea.

1. **Prepare:** Sketch the first shot and list the objects it needs before opening Maya.
2. **Model:** Shape meshes with Maya modeling tools so the blockout is clear.
3. **Rig:** Build controls with the Maya rigging workflow for animators.
4. **Animate:** Key the motion so Maya 3D animation matches the goal.
5. **Light:** Apply Maya Arnold rendering so materials and lighting preview correctly.
6. **Repeat:** Adjust scenes after each test, then move to caches and final output.
